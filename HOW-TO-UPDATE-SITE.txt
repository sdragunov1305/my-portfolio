Как обновить сайт fat-snail.com
(GitHub repo: my-portfolio)

Что в этом обновлении
- Кнопка Devlog ведёт на Telegram: https://t.me/Gamedev_Pedia
- Сборка под домен fat-snail.com (без пути /my-portfolio), чтобы стили и видео не ломались
- Форма влогов на /admin сохраняет посты в GitHub (нужен токен)

Как залить

1. Распаковать cursor-site-update.zip ИЛИ скопировать папку site-for-github.
2. Всё содержимое положить в КОРЕНЬ репозитория my-portfolio
   (рядом с package.json). Папки cursor-site быть не должно.
3. git add .
   git commit -m "Update: Devlog Telegram link, GitHub Pages for fat-snail.com"
   git push
   (или Commit + Push в GitHub Desktop)

4. GitHub → вкладка Actions → дождаться зелёного Deploy to GitHub Pages.

5. Settings → Pages:
   Source: Deploy from a branch
   Branch: gh-pages
   Folder: / (root)
   Custom domain: fat-snail.com
   Save, потом Enforce HTTPS.

6. Открыть https://fat-snail.com и нажать Ctrl+F5.

Не копировать: node_modules, .next, .env.local
